# 三维交互式个人博客 · 概念原型

一个不走传统“文章列表”路线的个人博客与网站：访客在三维场景中探索，文章安放在场景里专门的区域。整体结构为后续加入更多交互玩法预留了扩展空间。

目前包含四个可切换的主题方向（页面底部切换），都使用同一份文章数据和同一个文章阅读面板。

## 四个主题

| 文件夹 | 主题 | 简介 | 操作方式 |
| --- | --- | --- | --- |
| `src/scenes/E-浮空群岛` | 浮空群岛 | 云海之上的若干岛屿，每座岛代表一个栏目，岛与岛之间由桥相连 | 点击岛屿聚焦，点击空白返回 |
| `src/scenes/A-书房小屋` | 书房小屋 | 等距视角的小房间。书架是文章入口，书桌、唱片机、窗户等物件点击后会讲述自己的故事 | 纯鼠标点击、滚轮缩放 |
| `src/scenes/B-迷你星球` | 迷你星球 | 一颗可旋转的小星球，地标建筑对应不同栏目 | 环绕视角：拖动旋转、滚轮缩放；角色视角：W/S 前进后退、A/D 转向，靠近建筑按 E 进入，可乘船过海、走桥 |
| `src/scenes/C-文章银河` | 文章银河 | 每条旋臂对应一个标签，每篇文章是银河中的一颗星，离中心越远发布越早 | 远景整体浏览，拉近后附近的星星可交互（LOD 分级渲染） |

## 目录结构

```
src/
├── App.tsx                 # 外壳：品牌标题、主题切换、文章入口
├── main.tsx                # React 入口
├── index.css               # 全局样式、字体与 Tailwind 主题
├── components/
│   └── ArticlePanel.tsx    # 右侧文章面板（列表 / 详情）
├── data/
│   └── articles.ts         # 文章数据与标签配色
└── scenes/
    ├── types.ts            # 场景公共属性 SceneProps
    ├── E-浮空群岛/
    ├── A-书房小屋/
    ├── B-迷你星球/
    └── C-文章银河/
```

## 技术栈

React 19 · Vite · Tailwind CSS v4 · three.js · @react-three/fiber · @react-three/drei

## 成品：每个主题一个可直接打开的网页

运行 `pnpm build:themes` 后，会在 `成品/` 下为每个主题生成一个独立文件夹：

```
成品/
├── E-浮空群岛/index.html
├── A-书房小屋/index.html
├── B-迷你星球/index.html
└── C-文章银河/index.html
```

每个 `index.html` 已经把程序和样式全部打包在内，双击即可用浏览器打开（需联网加载字体）。场景里的贴图、模型都是代码实时生成的，没有额外的图片素材文件。

## 本地运行（开发）

```bash
pnpm install
pnpm dev
```

## 扩展指南

- **新增文章**：编辑 `src/data/articles.ts`，四个主题会同时生效。
- **新增主题**：在 `src/scenes/` 下新建文件夹，导出一个接收 `SceneProps`（`onOpenArticle`、`onOpenList`）的组件，再到 `App.tsx` 的 `concepts` 数组中注册即可。
