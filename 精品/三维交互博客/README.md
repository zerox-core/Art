# 三维交互式个人博客

不走传统"文章列表"路线的个人博客：访客在 3D 场景里探索，文章放在场景中专门的区域。共有四个主题方向，每个主题一个文件夹，**打开文件夹里的 `index.html` 就能直接体验**。

| 文件夹 | 主题 | 一句话 |
| --- | --- | --- |
| [E-浮空群岛](./E-浮空群岛) | 浮空群岛 | 云海上的浮岛，书岛是文章入口 |
| [A-书房小屋](./A-书房小屋) | 书房小屋 | 暖色小房间，书架是文章，物件会讲故事 |
| [B-迷你星球](./B-迷你星球) | 迷你星球 | 可以驾车/乘船/步行探索的小星球 |
| [C-文章银河](./C-文章银河) | 文章银河 | 每篇文章是一颗星，旋臂即分类 |

## 目录

```
三维交互博客/
├── E-浮空群岛/   index.html（成品） + README.md
├── A-书房小屋/   index.html（成品） + README.md
├── B-迷你星球/   index.html（成品） + README.md
├── C-文章银河/   index.html（成品） + README.md
└── 源码/         开发用的 React 工程，修改后可重新生成上面四个成品
```

## 修改与重新生成

```bash
cd 源码
pnpm install
pnpm dev            # 本地开发预览（四个主题可在底部切换）
pnpm build:themes   # 重新生成四个独立成品，输出到 源码/成品/
```

生成后把 `源码/成品/<主题>/index.html` 复制回对应主题文件夹即可。
