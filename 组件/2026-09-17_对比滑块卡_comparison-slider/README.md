# 对比滑块卡（滑动揭示两层文案）

单文件纯原生 HTML/CSS/JS 实现（无任何外部依赖，双击 `index.html` 即可在浏览器打开）。

来自「反转家教 Reverse Tutor」官网的对比模块：同一张卡片内叠放两层完整文案，拖动中间的细金线揭示比例，对比「普通 AI 聊天」与「反转家教」两种模式。文字始终固定不动，只有揭示，绝无推移。

## 结构（核心模型）

1. **底层 `.cmp-after`**（米色卡 · 反转家教层）——`position:relative` 正常文档流、铺满整个卡片宽，由它决定卡片高度
2. **顶层 `.cmp-before`**（纸白卡 · 普通AI层）——`position:absolute; inset:0` 同样铺满整卡宽，用 `clip-path:inset(0 calc(100% - var(--x)) 0 0)` 从左往右揭示
3. **分割线 `.cmp-line`**——2px 细金线，上下渐隐（18%/82% 处为实色），`left:var(--x)`
4. **把手 `.cmp-handle`**——36px 白底金边小圆 + `⇔`，挂在细线垂直中点

## 交互

- 按住细线/把手左右拖动，改变 `--x`（4% ~ 96%），拖动期间关闭过渡
- 拖到最左（4%）时顶层几乎完全裁掉，**底层全量显示、无遮挡**
- 点一下把手（没发生拖动时）→ 平滑摆到另一态（6% ↔ 76%）
- 窄屏（≤760px）自动退化为上下两块静态卡片，隐藏滑线

## 技术要点

- 揭示比例走 CSS 变量 `--x`，一条 `clip-path` 表达式驱动，无 JS 布局计算
- 文字零位移：两层各自完整排版，`clip-path` 只做裁切，不触发重排
- `pointerdown/move/up + setPointerCapture` 拖拽，`touch-action:none` 保证触屏可拖
- 过渡 `cubic-bezier(.22,1,.36,1)` 0.7s，仅作用于 `clip-path` 与 `left`

## 设计要点

- 浅米纸色系（`#f6f2e9` / `#f2ecdd` / `#faf9f6`）+ 哑光金（`#c8a45c`）点缀，无蓝紫、无发光
- 层级靠色差 + 1px 细边框，阴影只有 6% 透明度的一层
- 强调红仅用于标题「反转过来」一处
